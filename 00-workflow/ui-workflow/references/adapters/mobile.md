# 移动端适配（iOS / Android / 小程序 / 移动 H5）

只在移动端页面、移动 Web 或原生 App 任务加载。视觉风格以项目既有 Spec 为准，本文件只约束触控物理、安全区、软键盘与弱网低端设备韧性。

## 1. 视口与安全区物理避让（必须）

- 移动端页面必须声明覆盖完整屏幕视口（Web 配置 `viewport-fit=cover`），并以逻辑单位（`pt` / `dp` / `rem`）做布局，不按物理像素写死尺寸；不能用 `maximum-scale=1` 禁用用户缩放（破坏低视力可读性）。
- 顶部固定栏必须避让状态栏与异形屏刘海/打孔区（`env(safe-area-inset-top)`）。
- 底部固定栏与吸底主操作按钮必须叠加底部安全区（如 `max(16px, env(safe-area-inset-bottom))`），不能紧贴屏幕底边导致被系统手势条遮挡或误触返回桌面。

## 2. 触控热区与误触防护（必须）

- 最小可交互触控面积：iOS `≥ 44 × 44pt`，Android `≥ 48 × 48dp`。视觉图标较小时，必须通过外层容器或扩展命中区补足热区（手指触点远大于鼠标光标）。
- 相邻独立可点击目标之间至少保留 `8pt` 间隙，避免手指连带误触。
- 底部操作栏在多语言环境下不写死窄像素按钮宽，采用弹性占比或自动填充，确保长译文不截断、不挤爆主操作。

## 3. 软键盘治理（必须）

- **按字段语义唤起键盘**：手机号用 `tel`、纯数字用 `numeric`、小数金额用 `decimal`、邮箱用 `email`、搜索用 `search`、短信验证码配 `one-time-code` 自动填充；不能全部输入项退化为默认纯文本键盘。
- **防自动放大与防遮挡**：移动 Web 输入框字号必须 `≥ 16px`（防止聚焦时浏览器自动放大视口错位）；输入项聚焦时滚动到可见视口安全区，表单滚动容器底部预留垫高缓冲，且吸底按钮不能盖住正在输入的字段。
- **可预期收起**：支持点空白处收起、长列表开始滑动时收起、验证码填满或点击搜索/完成键时自动收起键盘。
- **表单轻量化**：单屏录入字段过多时拆分为分步或折叠分组，避免在窄屏形成压迫长表。

## 4. 导航、手势与底部抽屉

- **底部主导航（TabBar）**：一级入口控制在 3–5 个；进入二级及以下深层详情页时隐藏底部 TabBar，把垂直空间与安全区让给当前页内容与主操作。
- **红点与计数克制**：未读数定位在图标右上角并向左单向扩展（不遮盖主体图标），超限收敛为 `99+`；区分“待处理数字徽标”与“轻量无字提示点”，不对常规推广滥用红点。
- **手势只能提效，不能是唯一入口（必须）**：左滑删除、长按展开等手势必须存在可见点击入口；适老或大字模式下禁用复杂手势。
- **浮层优先底部抽屉（Bottom Sheet）**：移动端优先用从底部升起的半屏/多档抽屉（配顶部拖拽手柄与明确取消出口）替代居中大弹窗；居中模态仅用于高危二次确认。
- **锁死底层滚动穿透（必须）**：弹窗或半屏抽屉展开时，必须锁定底层主页面滚动并在关闭后准确恢复原滚动位置（结合 `overscroll-behavior: contain`）；含未提交录入的抽屉不能点遮罩静默丢失。

## 5. 窄屏列表与真实环境韧性

- 窄屏不直接塞入多列宽表格，转换为信息流卡片或主次清晰的可扫描列表；明确下拉刷新、触底加载、四类空态与失败重试出口，长列表采用虚拟滚动。
- **户外强光与低端机降级**：核心正文与状态严格满足对比度底线（`≥ 4.5:1`），不靠极浅灰文字承载关键信息；低端设备避免大面积实时背景模糊与复杂叠层物理动画，保证跟手帧率；弱网操作提供乐观反馈与失败回滚/重试路径。

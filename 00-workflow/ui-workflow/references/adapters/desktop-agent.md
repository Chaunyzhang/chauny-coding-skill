# 桌面端与 Agent 工作台适配

只在桌面应用（Electron / Tauri / 原生桌面壳）或 AI Agent 交互工作台任务加载。视觉风格以项目既有 Spec 为准；通用布局、弹层四分法与材质分层见 `references/craft/`，本文件只约束桌面窗口物理、焦点退让、裁切边界、输入法守卫与 Agent 任务状态真实性。

## 1. 桌面窗口、多栏焦点与原生交互语义（必须）

- **拖拽区与交互区严格隔离**：自定义无边框标题栏的窗口拖拽区（如 `-webkit-app-region: drag`）内，所有可点击、可输入、可选中控件必须显式声明不可拖拽（`no-drag`），不能让控件误触发整窗拖动。
- **多窗与多分栏失焦降亮退让**：当窗口失焦，或同屏多栏中某分栏不是当前键盘焦点区时，该区域的强调色选中态必须自动退化为低饱和中性灰底（确保用户一眼识别当前键盘按键会作用于哪个窗口与面板）。
- **无限边缘无死缝热区**：窗口贴边或最大化时，外沿滚动条与侧栏边缘点击热区必须紧贴容器真实边缘，不能留出 2–4px 点不到的死缝（边缘具有无限命中深度，死缝会破坏快速甩鼠标操作）。
- **右键上下文菜单纪律**：右键菜单只放与当前选中对象直接相关的常用动作，不能把整个应用的主菜单全塞进去；所有右键或快捷键动作在可见界面或主菜单中必须有对应入口。
- **捍卫原生语义与多窗隔离**：保留窗口控制、系统快捷键、焦点捕获与归还、文本选区、剪贴板与原生滚动；不把第三方自绘容器混同为系统原生菜单或文件弹窗；独立悬浮托盘窗失焦（`blur`）时收起并做图标点击防抖；多会话/多窗口切换时，各会话未发送草稿与已附加文件上下文相互隔离，不串扰不丢失；弹窗锁滚时配 `scrollbar-gutter: stable` 防止背景横向跳动。

## 2. 阴影裁切与遮罩物理边界（必须）

- **内外分层**：圆角内容裁切放内层容器，外投影与外发光放外层容器，不能让 `overflow: hidden` 切掉同一层或子元素的投影。
- **外扩安全余量**：若投影元素位于滚动容器或裁切祖先内，该侧到裁切边的留白必须 `≥ |offset| + blur + spread`（多层阴影取最大值）。无边框透明窗口必须同步扩大物理窗口尺寸与外层留白，不能只调 CSS padding。
- **禁止粗暴全局改 `overflow: visible`**：必须精确定位冲突裁切祖先并局部调整，避免破坏列表裁切与滚动边界；交付前在真实运行页面执行 `scripts/shadow-clip-audit.js` 验证零裁切。

## 3. 输入法安全、流式输出与分栏滚动（必须）

- **CJK IME 安全发送**：对话输入框监听 `compositionstart` / `compositionend` 并结合 `event.isComposing`（含伴生回车窗口），中文/日文/韩文输入法选词按 `Enter` 不能误触发消息发送；同时明确区分发送键与换行键并在输入区给出轻提示。
- **自适应输入与上限**：多行输入框随内容平滑扩展，到达 `max-height` 后转为内部滚动；若按视觉要求隐藏输入区滚动条，仅限该输入框本身且必须保留滚轮、触控板、选中与键盘滚动能力，不能全局隐藏页面滚动条。
- **流式输出智能跟随**：仅当用户处于底部容差范围内时随新输出自动贴底；一旦用户主动向上滚动查看上方输出，**立即冻结自动滚动**并显示轻量“回到底部”入口，不能强行把用户拉回底部。异步代码高亮或图片加载导致上方高度变化时，做好滚动位置补偿防视口跳动。
- **可拖拽分栏**：左右/上下多面板各自拥有独立滚动容器（配 `overscroll-behavior: contain`），不产生跨面板整页横滚；拖拽支持边界约束、记住用户拖拽宽度（Track State）与 `Escape` 取消复位。

## 4. Agent 任务状态机与用户控制权（必须）

- **状态严格绑定真实事件**：任务生命周期（草稿 `Drafting` → 排队 `Queued` → 执行中 `Running` → 等待授权 `Pending Approval` → 完成 `Completed` / 失败 `Failed` / 已中止 `Aborted`）必须来自后端或运行时真实事件，不能用前端计时器伪造进度或把“请求已受理”标成“已完成”。
- **可落实的五项控制权**：
  - **可见**：展示当前步骤、工具调用标识、关键输入参数与真实结果/错误；不把每个细碎事件拆成刷屏卡片，也不把模型纯文本 checklist 当作系统执行证据。
  - **可介入**：明确运行中或排队时用户能否编辑草稿、追加上下文或取消排队。
  - **可收回**：明确区分“已发出停止请求”与“已安全中止”，中止后保留已生成的阶段产物与失败原因，不清空现场。
  - **分级授权**：只读查询不反复弹窗打扰；写文件、删数据、执行高影响命令或外部发布时，授权卡片必须显式列出受影响目标路径/命令与范围。
  - **产物与落盘分界**：对话里的优化方案、预览视图的临时渲染、与实际写入本地/远端的落盘状态必须有清晰视觉边界，预览成功不等于已落盘。

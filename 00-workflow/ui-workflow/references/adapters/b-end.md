# B 端后台与数据密集界面适配

只在 B 端管理后台、表格列表、复杂表单、审批流或经营看板任务加载。视觉风格以项目既有 Spec 为准；通用交互防错、Undo/高危确认、选项量级、耗时三档与表单人因见 `references/craft/interaction-and-forms.md` 与 `layout-and-feedback.md`，本文件只约束 B 端专有结构。

## 1. 业务浮层选型与审批中立

按任务体量与是否需要对照底层列表选容器（通用四类容器边界与防丢规则见 `references/craft/interaction-and-forms.md`）：

| 形态 | 适用条件 | 禁用条件（AvoidWhen） |
|---|---|---|
| 行内轻确认（Popconfirm） | 高频、可逆或单行轻量动作，缩短指针动线 | 批量删除、资金变更、权限重置等高危不可逆动作 |
| 居中弹窗（Modal） | 短确认、少量字段聚焦录入（< 5 项）、宽幅预览 | 滚动超过 1.5 屏的长表单、需持续对照底层列表的编辑 |
| 侧边抽屉（Drawer） | 对象详情查看、多字段轻编辑、复杂筛选，且**需保留列表上下文** | 需独立 URL 分享协作的单据、多步骤向导、或仅一两句短提示 |
| 独立页面（Page） | 大型表单、分步向导、深度协作与可分享单据 | 几秒钟完成的单属性微调（导致丢失列表筛选与页码） |

- **审批中立（必须）**：审批「通过」与「驳回」等责任对等的二选一决策，必须采用同等视觉权重，不能用主次强调色诱导选择（防止视觉偏置影响审核判断）。

## 2. 数据表、筛选与批量操作

- **列对齐（必须）**：文本与状态列左对齐；数值、金额、百分比与定宽时间右对齐并启用 `tabular-nums`；定宽勾选或单图标列居中；表头与该列数据保持同侧对齐（确保纵向快速扫读不跳眼）。
- **滚动与窄屏保护（必须）**：超宽表格必须在表格容器内部横向滚动，不能撑出整页横向滚动条；固定列声明明确宽度并用边缘分隔指示滚动层；窄屏优先保留主键与操作列，不留无法横滚的半截残缺列。
- **操作列克制（必须）**：行内操作使用轻量无底色按钮；超过 3 项时只保留最高频 2 项，其余收进更多菜单（防止每行堆出操作墙压垮主数据）。
- **筛选按数量分层**：1–3 项单行内联；4–8 项默认露出核心项并支持折叠展开；9 项以上收进侧边高级筛选抽屉。大数据量或慢查询必须提供显式查询触发按钮，不能每敲一个字符就全表卡顿重查。
- **批量操作条**：未勾选时隐藏，勾选 ≥ 1 项后再浮出并明确展示已选数量、批量动作与一键清空选择。

## 3. 多语言弹性控件

- **禁止窄固定像素宽（必须）**：操作按钮与标签容器必须随文案弹性伸缩（设最小宽度与内边距），避免外文译文长度膨胀 2–3 倍后折行或溢出；国际化长表单优先采用标签置顶的上下排布。

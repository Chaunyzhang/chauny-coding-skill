# General Work Mode

没有 Execution Contract 时，本 Skill 仍适用于日常仓库工作。

开始时恢复 Active User Directive，并明确用户任务、修改边界、相关工程规则、Repository Reality 与最低充分 Verification。持续执行规则统一见 `execution-continuity.md`。

仍受全部 38 条雷点约束；只激活当前 Trigger 相关的额外检查。高频导航：

- bug fix：`2, 3, 5, 21, 22, 23, 27, 30, 31, 32, 33`
- refactor：`3, 6, 8, 9, 13, 16, 28`
- migration：`10, 11, 12, 13, 14, 17, 29`
- config：`2, 15, 19, 27`
- dependency：`2, 8, 15, 17, 20`
- debugging：`2, 21, 22, 23, 27, 30, 31, 32`
- test repair：`16, 17, 23, 24, 29, 32, 33, 34`

导航不表示其他规则失效。发现新的改进项、假想风险或“还能更保险”的方向不自动扩大工作；超出 Active User Directive 才需要新的授权/Trigger，同一 Objective 内尚未完成的合法工作不需要重复授权。
